# Prompt Engineering Academy

A beginner-friendly website that teaches users how to write effective prompts and get better results from AI tools.

## Features

- Learn Prompt Engineering basics
- Explore weak and strong prompt examples
- Interactive prompt builder
- Multiple-choice quiz
- Dark Mode and Light Mode
- English and Dari language support
- Responsive design

## Technologies

- React
- Tailwind CSS
- Vite
- Motion
